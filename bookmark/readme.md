# Bookmark Landing Page

A fully responsive landing page for the Bookmark app, built with HTML, Tailwind CSS, and Vanilla JavaScript. The project focuses on creating a clean, modern interface while ensuring a seamless experience across desktop, tablet, and mobile devices.

I developed the FAQ accordion section without using any JavaScript, relying solely on Tailwind CSS utility classes.

Vanilla JavaScript was also used to develop the tabbed features section.

### Features:
✅ Fully responsive layout.
✅ Built with Tailwind CSS utility classes.
✅ Clean and semantic HTML structure.
✅ Interactive hover and focus states.
✅ Cross-browser compatible.
✅ Optimized for performance and accessibility.

This project was developed as part of a Frontend Mentor coding challenge, with the goal of accurately converting the provided design into a pixel-perfect, responsive website while following modern front-end development best practices.
