# Fylo Landing Page

A fully responsive landing page for Fylo, built with HTML, Tailwind CSS, and Vanilla JavaScript. The project focuses on creating a clean, modern interface while ensuring a seamless experience across desktop, tablet, and mobile devices.

The standout feature of this project is the ability to switch between Light and Dark modes. This functionality was implemented using a combination of Vanilla JavaScript and Tailwind CSS utility classes, providing a smooth and intuitive user experience.

### Features:
✅ Fully responsive layout.
✅ Built with Tailwind CSS utility classes.
✅ Clean and semantic HTML structure.
✅ Light/Dark mode toggle with Vanilla JavaScript.
✅ Interactive hover and focus states.
✅ Cross-browser compatible.
✅ Optimized for performance and accessibility.
