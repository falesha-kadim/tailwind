# LoopStudios Landing Page

A fully responsive landing page for LoopStudios, built with HTML, Tailwind CSS, and JavaScript. The project showcases a modern, visually engaging design with a strong focus on responsive layouts, clean code, and an intuitive user experience across all devices. 

Vanilla JavaScript was also used for Hamburger menu.

### Features:
✅ Fully responsive layout.
✅ Built with Tailwind CSS utility classes.
✅ Clean and semantic HTML structure.
✅ Mobile navigation toggle with JavaScript.
✅ Interactive hover states.
✅ Cross-browser compatible.
✅ Optimized for performance and accessibility.

This project was developed as part of a Frontend Mentor coding challenge, with the goal of accurately converting the provided design into a pixel-perfect, responsive website while following modern front-end development best practices.

Design Source: Frontend Mentor Challenge (https://www.frontendmentor.io/challenges/loopstudios-landing-page-N88J5Onjw)
